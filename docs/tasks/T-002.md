## T-002 — Tasarım token'ları, fontlar, tema anahtarı, layout iskeletleri

**Ajan:** Frontend | **Öncelik:** P0 | **Bağımlılık:** T-001
**Faz:** F0 — Temel
**PROGRAM.md referansı:** §3 Tasarım Sistemi (3.1 renk, 3.2 tipografi, 3.3 layout, 3.4 hareket), §4.1/§4.2 Rotalar, §4.3 Klasör Yapısı, §5.2 Sert Kurallar, §10.1 Dosya Mülkiyeti, §10.6 DoD
**İlgili ADR:** ADR-002 (Tailwind v4 — `globals.css` içinde `@theme`, `tailwind.config.ts` yok)

**Amaç:** F2'den itibaren yazılacak her bileşenin dayanacağı görsel temeli kurmak: token'lar,
fontlar, FOUC'suz tema anahtarı, iki route group'un layout iskeleti ve temel UI primitifleri.
Bu bitmeden hiçbir sayfa yazılamaz.

**Kapsam (dokunulacak):**
- `src/app/globals.css` — §3.1 token'ları `@theme` içinde, koyu varsayılan + `.light` override, §3.3 boşluk/yarıçap skalası, `prefers-reduced-motion` global kuralı
- `src/app/layout.tsx` — kök layout: `next/font/google` (Space Grotesk, Inter, JetBrains Mono; `latin` + `latin-ext`, `display: swap`), `ThemeProvider`, `lang="tr"`, `suppressHydrationWarning`
- `src/app/page.tsx` — token/tipografi/tema doğrulama sayfası (geçici, F2'de değişecek)
- `src/app/(public)/layout.tsx` — Navbar + Footer iskeleti
- `src/app/(panel)/panel/layout.tsx` — Sidebar + Topbar iskeleti
- `src/app/(panel)/panel/page.tsx` — yer tutucu
- `src/components/ui/` — `Button`, `Card`, `Input`, `Label`, `Badge`, `Skeleton`, `EmptyState`
- `src/components/ui/theme-toggle.tsx`, `src/components/theme-provider.tsx`
- `src/components/public/{navbar,footer}.tsx`, `src/components/panel/{sidebar,topbar}.tsx`
- `src/lib/utils/cn.ts`

**Kapsam dışı (DOKUNULMAYACAK):**
- `package.json`, `pnpm-lock.yaml` — ADR-004: yeni bağımlılık kurulmaz
- `next.config.ts`, `tsconfig.json`, `postcss.config.mjs`, `eslint.config.mjs`
- `prisma/**`, `src/server/**`, `src/app/api/**`, `src/lib/schemas/**`, `src/types/**` — Backend'in
- `middleware.ts`, `tests/**`, CI dosyaları — Güvenlik ajanının
- `PROGRAM.md`, `docs/**` — Orkestra Şefi'nin
- React Bits bileşenleri — T-020'de kurulacak

**Kabul kriterleri:**
- [ ] §3.1'deki **her** token `@theme` içinde tanımlı; koyu varsayılan, `.light` sınıfı altında aydınlık override
- [ ] Hiçbir `.tsx` dosyasında hex renk kodu yok (`grep -rn "#[0-9a-fA-F]\{3,6\}" src --include=*.tsx` boş döner)
- [ ] Üç font `next/font/google` ile, `latin` + `latin-ext` subset, `display: swap`; CSS değişkeni olarak bağlanmış
- [ ] Türkçe karakterler (ğ ü ş İ ı ö ç) üç fontta da doğru görünüyor
- [ ] Tema anahtarı **cookie tabanlı** (localStorage değil), `next-themes` ile; sayfa yenilendiğinde **FOUC yok**
- [ ] Sistem teması algılanıyor; kullanıcı seçimi sistemi geçersiz kılıyor
- [ ] `prefers-reduced-motion: reduce` aktifken tüm geçişler `0.01ms`'e iniyor (global CSS kuralı)
- [ ] `.tabular` yardımcısı: JetBrains Mono + `font-variant-numeric: tabular-nums` (§3.2 panel gereksinimi)
- [ ] 7 UI primitifi mevcut, hepsi klavye erişilebilir, görünür focus halkası var, 360px'te bozulmuyor
- [ ] `EmptyState` bir eylem daveti (action slot) alıyor — sadece "veri yok" yazmıyor
- [ ] `/` sayfası tüm token'ları, tip ölçeğini ve tema anahtarını gösteriyor
- [ ] `/panel` yer tutucu, Sidebar + Topbar ile render oluyor
- [ ] `pnpm lint && pnpm typecheck && pnpm build` temiz
- [ ] Panelde hiçbir WebGL/shader/ağır efekt yok (§5.2.1)

**Test:** Bu görevde otomatik test yazılmaz (altyapı T-004'te kurulacak).
Doğrulama: yukarıdaki dört komut + tarayıcıda koyu/aydınlık geçiş, 360px genişlik ve
klavye ile tam gezinme kontrolü. Raporda ekran kontrolü sonuçları yazılır.

**Dışarıya sözleşme (raporda mutlaka belirtilecek):**
- Token adlarının tam listesi (`--bg-base` … `--info`) ve Tailwind'de nasıl çağrıldıkları
- Font CSS değişken adları (`--font-display`, `--font-body`, `--font-mono`)
- UI primitiflerinin prop imzaları
- Tema anahtarının çalışma biçimi (cookie adı, sınıf stratejisi)
- `cn()` yardımcısının imzası
