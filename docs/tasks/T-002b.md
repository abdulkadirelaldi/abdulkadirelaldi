**Kabul kriterleri:**
- [ ] `color-contrast` denetimi **geçiyor**; §3.1'in tüm metin/zemin çiftleri **her iki temada** AA'yı sağlıyor (normal metin ≥ 4.5:1, büyük metin ≥ 3:1)
- [ ] Kontrast oranları **ölçülmüş sayı olarak** raporda listeleniyor — "düzelttim" yetmez
- [ ] `--text-muted` dahil edildi: en riskli token bu, `--bg-surface` üzerindeki oranı verilmeli
- [ ] `link-in-text-block` geçiyor: gövde metni içindeki bağlantılar renk **dışında** bir işaretle de ayırt ediliyor (alt çizgi önerilir)
- [ ] Navigasyon/buton gibi blok bağlamındaki bağlantılar bu kuraldan etkilenmiyor — gövde metni içi ile ayrımı net
- [ ] `errors-in-console` geçiyor — konsolda hata yok
- [ ] Lighthouse **Accessibility ≥ 0.95** (yerelde ölç, çıktıyı raporda paylaş)
- [ ] Performance düşmedi (T-005 ölçümü: 91)
- [ ] `viewport.themeColor` ayarlandı — `layout.tsx` içinde, ilgili token'a işaret eden yorumla (PROGRAM.md §3.1'in yeni istisna kuralı buna izin veriyor)
- [ ] Değişen token değerleri raporda **eski → yeni** olarak listeleniyor (PROGRAM.md §3.1 güncellemesi buna göre yapılacak)
- [ ] `pnpm lint && pnpm typecheck && pnpm test && pnpm build` temiz
