## T-015b — TOTP Server Action'ları

**Ajan:** Backend | **Öncelik:** P0 | **Bağımlılık:** T-015, T-036
**Faz:** F1 — Veri & Auth · **F1'in tek kalan engeli**
**Kaynak:** T-036 → ENGEL-1, ENGEL-5
**PROGRAM.md referansı:** §7.1, §8.1, §8.6, §8.19 · **ADR:** 013, 020, 022

**Amaç:** 2FA ekranı hazır ama `src/server/actions/` **boş**. Kripto primitifleri (T-013a)
ve servis konvansiyonu (T-015) hazır; eksik olan tek şey bunları sıraya dizen, `totpConfirmedAt`'i
dolduran ve kurtarma kodlarını üreten katman. **§8.1'in "2FA zorunlu açık gelir" ifadesi
bu gelene kadar kağıt üzerinde.**

**Frontend'in yayınladığı sözleşme** (`src/components/auth/totp-contract.ts` — tipli, hazır):
```ts
getTotpStatus(): Promise<{ enabled: boolean; remainingBackupCodes: number }>
startTotpSetup(): Promise<{ ok:true; data:{ secret; otpauthUri } } | { ok:false; error }>
confirmTotpSetup(totpCode): Promise<{ ok:true; data:{ backupCodes; remainingBackupCodes } } | …>
regenerateBackupCodes(totpCode): Promise<…>
```
Hata kodları: `UNAUTHORIZED` · `INVALID_TOTP` · `ALREADY_ENABLED` · `NOT_ENABLED` ·
`RATE_LIMITED` · `INTERNAL_ERROR`.

**Kapsam:** `src/server/actions/totp.ts` · `src/server/services/user.ts` (gerekirse) ·
`tests/unit/actions/`

**Kapsam dışı:** `src/components/**`, `src/app/**` (Frontend'in — eylemler gelince sayfa
tek import ile canlanacak, bileşende değişiklik **gerekmiyor**) · `src/lib/security/**`,
`src/middleware.ts`, `tests/e2e/**` (Güvenlik'in) · `prisma/schema.prisma` · `package.json`

**Kabul kriterleri:**
- [ ] Dört eylem de T-015'in konvansiyonuna uyuyor: `auth()` → Zod → servis → `AuditLog` → `revalidatePath`
- [ ] Her eylem **kendi içinde** `auth()` çağırıyor (§8.6 — middleware'e güvenilmez)
- [ ] `startTotpSetup`: secret üretir, **`TOTP_ENCRYPTION_KEY` ile şifreler**, saklar — `totpConfirmedAt`'i **DOLDURMAZ**
- [ ] `confirmTotpSetup`: **yalnızca burada** `totpConfirmedAt` dolar; kurtarma kodları üretilir, argon2id ile hash'lenir, **düz metin sadece bu yanıtta** döner
- [ ] Yanlış kodda 2FA etkinleşmiyor ve secret **silinmiyor** (kullanıcı tekrar deneyebilmeli)
- [ ] `regenerateBackupCodes` **uygulanıyor — opsiyonel değil** (ENGEL-5): kodlar bitince kullanıcı yalnızca TOTP'ye bağımlı kalmamalı. Geçerli TOTP ister — oturumu ele geçiren biri tek tıkla kod üretememeli
- [ ] `ALREADY_ENABLED` / `NOT_ENABLED` doğru durumlarda dönüyor
- [ ] Dört olay da `AuditLog`'a yazılıyor (ADR-022: **sonuçlar** yazılır) — `writeAuditLog` kullanılıyor, elle yazılmıyor
- [ ] Denetim kaydında secret, kurtarma kodu veya hash **yok** (redaksiyon otomatik ama **doğrula**)
- [ ] `RATE_LIMITED`: kurulum doğrulaması da hız sınırına tabi — sınırsız TOTP denemesi kaba kuvvete açık olurdu
- [ ] Birim testleri: her eylem için başarı + her hata kodu; kapsam ≥ %90
- [ ] `pnpm lint && typecheck && test && build` temiz; `.env` olmadan da build EXIT 0

**Dışarıya sözleşme:** dört eylemin nihai imzaları (Frontend `totp-contract.ts`'i buna göre
doğrulayacak) · `AuditLog` kayıtlarının şekli · hız sınırının eşiği ve nereden geldiği.
