## T-003 — Prisma bağlantısı, dev Postgres, sağlık kontrolü ucu

**Ajan:** Backend | **Öncelik:** P0 | **Bağımlılık:** T-001
**Faz:** F0 — Temel
**PROGRAM.md referansı:** §2 Teknoloji Yığını, §4.3 Klasör Yapısı, §7.1/§7.2 API Sözleşmesi, §12 Ortam Değişkenleri, §13.6 Sağlık Kontrolü
**İlgili risk:** R8 — Prisma **7.9.1** kuruldu; v6'ya göre kırıcı değişiklikler var

**Amaç:** Veritabanı bağlantısını ve sağlık kontrolü ucunu kurmak. F1'in tamamı (tam şema,
auth, servisler) bu bağlantının üzerine binecek; Prisma 7'nin generator ve import yolu
burada netleşip sözleşme olarak yayınlanmalı.

**Kapsam (dokunulacak):**
- `prisma/schema.prisma` — **yalnızca** `datasource` + `generator` + tek doğrulama modeli (`HealthCheck` veya eşdeğeri). §6'nın tam modeli T-010'da.
- `src/server/db.ts` — tekil (singleton) Prisma istemcisi; dev'de hot reload'ta yeniden bağlanmayı önleyen global kalıp
- `src/app/api/v1/health/route.ts` — §13.6: DB bağlantısı + disk kontrolü
- `docker-compose.dev.yml` — yerel Postgres 16, kalıcı volume, portu **yalnızca** localhost'a bağla
- `prisma/migrations/` — ilk migration
- `README.md` — yerel kurulum adımları (compose başlat → migrate → dev)

**Kapsam dışı (DOKUNULMAYACAK):**
- `package.json` — ADR-004: yeni bağımlılık kurulmaz. Prisma script'i (`db:migrate` vb.) gerekiyorsa raporda **talep et**, kendin ekleme.
- `src/app/globals.css`, `src/app/layout.tsx`, `src/app/page.tsx`, `src/components/**`, `src/app/(public)/**`, `src/app/(panel)/**` — T-002'de Frontend ajanı **aynı anda** bunlar üzerinde çalışıyor
- `middleware.ts`, `tests/**`, CI dosyaları — Güvenlik ajanının
- `src/lib/schemas/**` — T-011'de
- `PROGRAM.md`, `docs/**`
- Gerçek `.env` dosyası oluşturma (yerelde `.env` yaratabilirsin ama repoya girmez — `.gitignore` zaten yasaklıyor)

**Kabul kriterleri:**
- [ ] `docker compose -f docker-compose.dev.yml up -d` ile Postgres 16 ayağa kalkıyor; port `127.0.0.1:5432` ile sınırlı (dışarı açık değil)
- [ ] `pnpm exec prisma migrate dev` ilk migration'ı üretiyor, `prisma/migrations/` altında dosya var
- [ ] `pnpm exec prisma generate` hatasız; üretilen istemcinin **konumu ve import yolu** raporda açıkça yazılı (Prisma 7 — R8)
- [ ] `src/server/db.ts` tekil istemci döndürüyor; dev'de hot reload sırasında bağlantı havuzu tükenmiyor
- [ ] `GET /api/v1/health` sağlıklı durumda `200` + `{ ok: true, data: { db: "up", uptime: number, ... } }`
- [ ] DB kapalıyken `503` + `{ ok: false, error: { code: "INTERNAL_ERROR", message: ... } }` — §7.2 zarfına birebir uygun
- [ ] Hata yanıtında **stack trace, bağlantı dizesi veya host adı yok** (§7.2, §8.20)
- [ ] Uç `force-dynamic` — önbelleğe alınmıyor
- [ ] `pnpm lint && pnpm typecheck && pnpm build` temiz (build sırasında DB'ye bağlanmaya çalışmıyor)
- [ ] `.env` repoda yok

**Test:** Bu görevde otomatik test yazılmaz (altyapı T-004'te kurulacak).
Doğrulama: `/api/v1/health` ucunun hem DB açıkken hem kapalıyken çıktısı raporda paylaşılır.

**Dışarıya sözleşme (raporda mutlaka belirtilecek):**
- Prisma 7 generator yapılandırması + üretilen istemcinin import yolu (T-010 ve tüm servisler buna bakacak)
- `src/server/db.ts` export imzası
- `/api/v1/health` başarı ve hata gövdelerinin tam JSON şekli
- `docker-compose.dev.yml` servis adı, port, volume adı, DB adı/kullanıcı
- `DATABASE_URL` yerel biçimi
