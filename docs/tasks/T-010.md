## T-010 — Tam Prisma şeması (§6 + §6.1) + ilk migration

**Ajan:** Backend | **Öncelik:** P0 | **Bağımlılık:** T-003b, ADR-013…021
**Faz:** F1 — Veri & Auth (açılış görevi)
**PROGRAM.md referansı:** §6 Veri Modeli, **§6.1 Bağlayıcı Düzeltmeler**, §7.3, §8.20, §12
**İlgili ADR:** 013 (auth), 014 (para), 015 (tekrarlayan), 016 (tarih), 017 (ilişki), 018 (dosya), 019 (içerik), 020 (enum), 021 (spor/hayat)

**Amaç:** F1'in tamamının üzerine bineceği veri modelini **tek seferde** yazmak. Backend'in
T-000 değerlendirmesindeki 30 kalem karara bağlandı; şema artık parça parça değil bütün
olarak yazılabilir — migration zincirinin kirlenmemesi için de böyle yazılmalı.

**Kapsam (dokunulacak):**
- `prisma/schema.prisma` — §6'nın tüm varlıkları, **§6.1 tablosuna göre düzeltilmiş**
- `prisma/migrations/` — tek migration; `HealthCheck` modelinin kaldırılması **aynı migration'a girsin**
- `src/types/index.ts` — enum'lardan türeyen paylaşılan tipler (gerekiyorsa)
- `.env.example` — `TOTP_ENCRYPTION_KEY` (ADR-013, §12'ye eklendi)
- `package.json` — **yalnızca** `next-themes` bağımlılığının kaldırılması (ADR-010 onayı)

**Kapsam dışı (DOKUNULMAYACAK):**
- `src/lib/schemas/**` — Zod şemaları **T-011**, ayrı görev
- `prisma/seed.ts` — T-012
- `src/server/auth.ts`, Auth.js kurulumu — T-013
- `src/server/services/**` — T-015
- `src/server/db.ts` — T-003c'deki hâli doğru
- `src/middleware.ts`, `tests/**`, `.github/**`, `lighthouserc.json` — Güvenlik ajanının
- `src/app/**`, `src/components/**` — Frontend'in (T-020 paralel koşuyor)
- `package.json`'da `next-themes` dışındaki hiçbir şey

**Kabul kriterleri:**
- [ ] §6'daki **tüm** varlıklar mevcut; §6.1 tablosundaki **her** düzeltme uygulanmış
- [ ] `Session` ve `VerificationToken` **yok**; `Account` **yok** (ADR-013)
- [ ] `User`: `totpBackupCodes`, `totpConfirmedAt`, `lockedUntil` var; `totpSecret` şifreli saklanacak şekilde tasarlanmış
- [ ] `LoginAttempt` modeli var, `emailHash` (ham e-posta değil), `@@index([ip, createdAt])`
- [ ] `Transaction` ve `Job`: `fxRate Decimal(18,8)` + `baseAmount Decimal(12,2)`
- [ ] `Transaction`'da `isRecurring`/`recurrenceRule`/`attachmentId` **yok**; `RecurringTransaction` modeli var; `@@unique([sourceRecurringId, periodKey])`
- [ ] Gün alanları `@db.Date`: `HealthLog`, `HabitLog`, `Transaction`, `Workout`, `JournalEntry`
- [ ] `ContactMessage.convertedJobId` **yok**; `Job.contactMessageId String? @unique` var
- [ ] `Client.email String? @unique`
- [ ] `TransactionCategory`, `Exercise`, `Client`, `Habit`: `isArchived` + bağlı FK'ler `onDelete: Restrict`
- [ ] `Attachment`: `url` **yok**; `key @unique`, `checksum`, `width?`, `height?`, `uploadedById`, `@@index([entity, entityId])`
- [ ] `coverAttachmentId` / `avatarAttachmentId` / `cvAttachmentId` FK'leri `onDelete: Restrict`; `Project.gallery` **ilişki**
- [ ] İçerik modellerinde `locale String @default("tr")`, slug kısıtları `@@unique([slug, locale])`
- [ ] İçerik `status` enum'u: `DRAFT` · `SCHEDULED` · `PUBLISHED` · `ARCHIVED`
- [ ] `Post.viewCount` doğrudan sütun **değil** (ADR-019)
- [ ] `AuditLog`: `actorId onDelete: SetNull` + `actorEmailHash`
- [ ] `ContactMessage`: `repliedAt`, `archivedAt`, `honeypotHit`, `spamScore`
- [ ] `PersonalRecord`: `@@unique([exerciseId, reps])` + `workoutSetId String? @unique onDelete: SetNull`
- [ ] `HabitLog`: `done` **yok**, `count Int @default(1)`, `@@unique([habitId, date])`; `Habit.targetPerDay Int?`
- [ ] `Profile`: tekil kullanım için sabit id tasarımı
- [ ] ADR-017'deki **asgari indeks seti** uygulanmış
- [ ] Tüm kategorik alanlar **enum** (ADR-020); `mood` ve `feeling` `Int` (1–5 ölçek)
- [ ] `HealthCheck` modeli kaldırıldı, drop **aynı migration'da**
- [ ] `pnpm exec prisma migrate dev` tek migration üretiyor; `prisma migrate status` temiz
- [ ] `next-themes` `package.json`'dan kaldırıldı; `pnpm install` sonrası hiçbir şey kırılmadı
- [ ] `pnpm lint && pnpm typecheck && pnpm test && pnpm build` temiz; `.env` **olmadan** da build EXIT 0

**Test:** Bu görevde birim testi yazılmaz (şema katmanı). T-011'den itibaren Zod şemaları
ve servisler test edilecek. Doğrulama: `migrate dev` + `migrate status` + `prisma validate`
çıktıları ve kapı komutları.

**Dışarıya sözleşme (raporda mutlaka belirtilecek) — Frontend ve Güvenlik buna bakacak:**
- **Tüm enum'ların tam değer listeleri** (§7.3 — Frontend bunları kodunda kullanacak)
- Model adları ve alanları, özellikle F3/F4'te tüketilecek olanlar
- `Decimal` alanların listesi (T-015'te `string`'e çevrilecekler — ADR-014)
- `@db.Date` alanların listesi (ADR-016 zaman dilimi yardımcısı bunlara uygulanacak)
- `onDelete` politikaları — Frontend "silinemiyor" durumunu UI'da karşılamak zorunda
- `periodKey` üretim kuralı (ADR-015)
- Migration adı ve uygulanma çıktısı
