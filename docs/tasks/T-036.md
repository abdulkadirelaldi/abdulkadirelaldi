## T-036 — 2FA kurulum ekranı: QR, doğrulama, kurtarma kodları

**Ajan:** Frontend | **Öncelik:** P0 | **Bağımlılık:** T-013c
**Faz:** F1 — Veri & Auth (**F3'ten alındı — Q7 kararı**)
**PROGRAM.md referansı:** §3, §8.1, §8.3, §10.6 · **ADR:** 013

**Amaç:** §8.1 "2FA v1'de zorunlu olarak açık gelir" diyor ama **2FA'yı açacak ekran yok.**
Seed `totpConfirmedAt`'i boş bırakıyor ve sistem şu an 2FA'sız çalışıyor. Ayrıca kurtarma
kodları kullanıcıya hiç gösterilmediği için ADR-013'ün kurtarma yolu pratikte kullanılamıyor
— `/giris` kodu kabul etmeye hazır ama üretilip gösterilen bir kod yok.
**F1'in kabul kapısı bu ekran olmadan dürüstçe kapanamaz.**

**Kapsam (dokunulacak):**
- `src/app/(panel)/panel/ayarlar/guvenlik/page.tsx` (veya §4.2'ye uygun bir yol)
- `src/components/auth/totp-setup.tsx` — QR + doğrulama + kurtarma kodu gösterimi
- `src/components/ui/**` — gerekiyorsa yeni primitif

**Kapsam dışı (DOKUNULMAYACAK):**
- `src/server/**`, `src/app/api/**`, `prisma/**`, `src/lib/schemas/**` — Backend'in.
  **Gereken Server Action yoksa `Engeller` bölümüne yaz, geçici uç yazma.**
- `src/middleware.ts`, `src/lib/security/**`, `tests/**` — Güvenlik ajanının (T-016 paralel)
- `package.json` — QR üretimi için kütüphane gerekiyorsa **talep et**, kurma
- React Bits — T-020

**Backend'in hazır sözleşmesi (T-013a):**
- `buildTotpUri(secret, accountLabel)` → `otpauth://` URI (QR'a gömülecek)
- `generateBackupCodes()` → **10 adet**, `XXXXX-XXXXX` biçiminde, alfabe `ACDEFGHJKMNPQRTUVWXY34679`
- `loginCodeSchema` (T-013c) — doğrulama alanı için, kendi kopyanı **sil**

**Kabul kriterleri:**
- [ ] QR kod gösteriliyor **ve** secret düz metin olarak da veriliyor (QR okuyamayan için)
- [ ] Kullanıcı bir TOTP kodu girip **doğrulamadan** 2FA etkinleşmiyor (`totpConfirmedAt` ancak doğrulamadan sonra dolar)
- [ ] Kurtarma kodları **yalnızca bir kez** gösteriliyor; bu ekranda net biçimde uyarılıyor
- [ ] "Kopyala" ve "İndir" eylemleri var — kullanıcı kodları kaybetmemeli
- [ ] Kullanıcı kodları kaydettiğini **açıkça onaylamadan** akış kapanmıyor
- [ ] Kalan kurtarma kodu sayısı gösteriliyor (T-013b sözleşmesi)
- [ ] Secret ve kodlar **URL'ye, `localStorage`'a veya konsola yazılmıyor** (T-017/K5 dersi: hidrasyon öncesi form gönderimi de sızdırabilir — `method="post"`)
- [ ] Klavye ile tam gezinilebilir, `role="alert"`, 360px'te bozulmuyor, iki temada doğru
- [ ] Hiçbir `.tsx`'te hex yok
- [ ] Sayfa `robots: { index: false }` (panel altında, T-014 zaten koruyor)
- [ ] `pnpm lint && typecheck && build` temiz

**Test:** Otomatik test yazma — `tests/**` Güvenlik ajanının. Elle doğrula: QR okunuyor mu,
yanlış kod reddediliyor mu, kodlar bir kez gösteriliyor mu, iki tema, klavye, 360px.

**Dışarıya sözleşme:** ekranın rotası · Backend'den talep edilen Server Action imzaları
(varsa) · kurtarma kodu gösterim akışının adımları — T-016 buna E2E yazabilir.
