## T-003c — BULGU-002 düzeltmesi: `pg` havuzunu tembel kur

**Ajan:** Backend | **Öncelik:** P0 | **Bağımlılık:** T-003b
**Faz:** F0 — Temel
**PROGRAM.md referansı:** §8.17 (`.env` repoya girmez), §13 (Docker/CI derlemesi)
**Kaynak:** T-004 raporu → BULGU-002 (Yüksek) · **Risk:** R13

**Amaç:** `.env` olmadan `pnpm build` düşüyor. CI'da ve Docker build katmanında `.env`
bulunmaz (§8.17 zaten yasaklıyor), dolayısıyla T-005 ve T-070 bu hâliyle kurulamaz.
Havuz modül yüklenirken değil, ilk kullanımda kurulacak.

**Neden şimdi:** `@/server/db`'nin bugün tek tüketicisi var. T-015'ten sonra onlarca
servis dosyası bu modülü import edecek ve aynı düzeltme çok daha pahalı hale gelecek.

**Doğrulanmış hata:**
```
$ mv .env .env.bak && pnpm build
✓ Compiled successfully in 1130ms
  Collecting page data ...
Error: DATABASE_URL tanımlı değil. .env dosyasını kontrol edin (bkz. .env.example).
    at .next/server/app/api/v1/health/route.js
[Error: Failed to collect page data for /api/v1/health]
EXIT 1
```
Orkestra Şefi tarafından bağımsız olarak yeniden üretildi. T-003b raporundaki
"`.env` olmadan build çalışır" notu **hatalıydı** — o ölçüm DB kapalıyken yapılmıştı,
`.env` yerindeydi. İkisi farklı senaryo.

**Kapsam (dokunulacak):**
- `src/server/db.ts` — havuz ve istemci tembel (lazy) kurulur

**Kapsam dışı (DOKUNULMAYACAK):**
- `src/app/api/v1/health/route.ts` — `pingDatabase()` imzası korunacak, uç değişmemeli
- `package.json`, `prisma/**`, `prisma.config.ts`
- `middleware.ts`, `src/lib/security/**`, `tests/**`, `vitest.config.ts`, `playwright.config.ts` — Güvenlik ajanının
- `src/app/globals.css`, `src/app/layout.tsx`, `src/app/page.tsx`, `src/components/**`, `src/app/(public)/**`, `src/app/(panel)/**` — Frontend'in
- `next.config.ts`, `tsconfig.json`
- `docs/**`, `PROGRAM.md`

**Kabul kriterleri:**
- [ ] `.env` **olmadan** `pnpm build` → EXIT 0 (bu görevin varlık sebebi)
- [ ] `.env` **olmadan** `pnpm install`, `pnpm typecheck`, `pnpm lint`, `pnpm test` → hepsi EXIT 0
- [ ] `DATABASE_URL` eksikken hata hâlâ fırlatılıyor — ama **modül yüklenirken değil, ilk DB erişiminde**
- [ ] Hata mesajı §8.20 uyumlu: anahtar adı var, değer/host/kullanıcı yok
- [ ] `export const db: PrismaClient` **imzası değişmedi** — T-003b sözleşmesi korunuyor, F1 servisleri etkilenmiyor
- [ ] `pingDatabase(): Promise<void>` imzası değişmedi
- [ ] Hot reload havuz sızıntısı yok — `globalThis` kalıbı korunuyor, ölçümle doğrulandı
- [ ] `GET /api/v1/health` davranışı aynı: DB açık `200`, DB kapalı `503`
- [ ] Havuz ayarları (`max: 10`, `idleTimeoutMillis: 30_000`, `connectionTimeoutMillis: 5_000`) aynen duruyor
- [ ] `onPoolError` / `onConnectionError` bağlı kalıyor
- [ ] `pnpm lint && pnpm typecheck && pnpm test && pnpm build` temiz

**Test:** Güvenlik ajanının test altyapısı artık hazır (`pnpm test`, DB'siz ve `.env`'siz koşar).
Bu görevde `tests/**` **senin değil** — test yazma. Doğrulamayı komut çıktısıyla yap ve
`.env`'li / `.env`'siz iki senaryoyu da raporla.

**Dışarıya sözleşme (raporda mutlaka belirtilecek):**
- `src/server/db.ts` export imzalarının **değişmediğinin** teyidi
- `.env`'siz `pnpm build` çıktısı (EXIT kodu dahil)
- Tembel kurulumun hot reload davranışını nasıl etkilediği
