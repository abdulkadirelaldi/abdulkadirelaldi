## T-001 — Next.js 15 iskeleti, toolchain ve klasör yapısı

**Ajan:** Backend | **Öncelik:** P0 | **Bağımlılık:** —
**Faz:** F0 — Temel
**PROGRAM.md referansı:** §2 Teknoloji Yığını, §4.3 Klasör Yapısı, §10.1 Dosya Mülkiyeti, §10.5 Git Düzeni, §12 Ortam Değişkenleri
**İlgili ADR:** ADR-002 (Tailwind v4), ADR-003 (pnpm), ADR-004 (tek elden bağımlılık kurulumu)

**Amaç:** Projenin çalışan iskeletini kurmak — diğer üç ajanın üzerine kod yazacağı zemin.
Bağımlılıklar ADR-004 gereği tek seferde burada kurulur, böylece paralel çalışacak
Frontend ve Güvenlik ajanları `package.json` üzerinde çakışmaz.

**Kapsam (dokunulacak):**
- `package.json`, `pnpm-lock.yaml`, `.npmrc`
- `tsconfig.json`, `next.config.ts`, `postcss.config.mjs`
- `eslint.config.mjs`, `.prettierrc`, `.prettierignore`, `.editorconfig`
- `.gitignore`, `.env.example`
- `src/app/layout.tsx`, `src/app/page.tsx`, `src/app/globals.css` — **yalnızca derlenebilir yer tutucu**
- `src/lib/constants.ts`, `src/types/index.ts`
- Boş klasör iskeleti + `.gitkeep`: `src/app/(public)/`, `src/app/(panel)/panel/`, `src/app/api/v1/`,
  `src/components/{ui,reactbits,public,panel}/`, `src/server/{actions,services}/`,
  `src/lib/{schemas,utils,security}/`, `prisma/migrations/`, `tests/{unit,e2e}/`
- `README.md`

**Kapsam dışı (DOKUNULMAYACAK):**
- `PROGRAM.md`, `docs/**` — Orkestra Şefi'nin
- `middleware.ts`, `vitest.config.ts`, `playwright.config.ts`, `.github/**` — Güvenlik ajanının (T-004)
- `prisma/schema.prisma`, `src/server/db.ts` — T-003'te yapılacak
- `globals.css` içinde tasarım token'ı tanımlamak, font kurmak, tema anahtarı yazmak — Frontend'in (T-002)
- Herhangi bir React Bits bileşeni kurmak

**Kabul kriterleri:**
- [ ] `pnpm install` temiz çalışıyor, `packageManager` alanı pnpm sürümünü sabitliyor
- [ ] `pnpm dev` hatasız ayağa kalkıyor, `/` yer tutucu sayfa dönüyor
- [ ] `pnpm build` başarılı; `next.config.ts` içinde `output: 'standalone'` var
- [ ] `pnpm typecheck` temiz; `tsconfig.json` içinde `strict: true`, `noUncheckedIndexedAccess: true`, `@/*` path alias `src/*`'e bakıyor
- [ ] `pnpm lint` sıfır uyarı; ESLint kuralları `no-explicit-any` ve `ban-ts-comment` için **error** seviyesinde
- [ ] `package.json` scripts: `dev`, `build`, `start`, `lint`, `typecheck`, `format`, `test`, `test:e2e`
- [ ] §4.3'teki klasör ağacının tamamı mevcut
- [ ] `.env.example` §12'deki **tüm** anahtarları değersiz içeriyor; `.gitignore` `.env*` dosyalarını (`.env.example` hariç) dışlıyor
- [ ] Repoda hiçbir `.env` dosyası yok; `package-lock.json` / `yarn.lock` yok
- [ ] Kurulmuş bağımlılıklar (aşağıdaki liste) eksiksiz ve sürümleri `package.json`'da sabit

**Kurulacak bağımlılıklar (ADR-004 — tam liste, fazlasını ekleme):**
- Çekirdek: `next@15`, `react`, `react-dom`, `typescript`
- Stil: `tailwindcss@4`, `@tailwindcss/postcss`, `clsx`, `tailwind-merge`
- Veri: `prisma` (dev), `@prisma/client`
- Auth: `next-auth@beta` (v5), `@auth/prisma-adapter`, `argon2`, `otplib`
- Doğrulama/form: `zod`, `react-hook-form`, `@hookform/resolvers`
- UI/hareket: `next-themes`, `framer-motion`, `recharts`, `lucide-react`
- İçerik: `next-mdx-remote`, `rehype-sanitize`, `remark-gfm`
- Tarih/format: `date-fns`
- Lint: `eslint`, `eslint-config-next`, `@typescript-eslint/*`, `prettier`, `prettier-plugin-tailwindcss`
