## T-013e — BULGU-008: JWT'ye `tfa` alanı + kurulum sonrası oturum tazeleme

**Ajan:** Backend | **Öncelik:** P0 | **Bağımlılık:** T-019
**Faz:** F1 — **kapanış maddesi** · **Kaynak:** T-019 → BULGU-008
**PROGRAM.md:** §8.1 (güncellendi), §8.3, §8.20

**Amaç:** Güvenlik ajanı §8.1 kapısını kurdu ve kanıtladı — ama kapı `tfa` alanını okuyor,
giriş akışı ise alanı jetona koymuyor. **Bugün gerçek bir kullanıcı 2FA'sız panele girebiliyor.**
F1'in kabul kapısı bu iki satır olmadan dürüstçe kapanmaz.

**Kapsam:** `src/server/auth.ts` · `src/server/auth/credentials.ts` (gerekirse) ·
`tests/unit/auth/`

**Kapsam dışı:** `src/lib/security/**` (Güvenlik'in — `requiresTwoFactorSetup` **tüketilir**) ·
`src/app/**`, `src/components/**` · `prisma/**`, `package.json`

**İstenen (tam kod `docs/security/README.md` → BULGU-008):**
1. `authorize` dönen nesneye `tfa: result.user.twoFactorEnabled` eklensin
2. `jwt` geri çağrısı `token.tfa = user.tfa` yazsın

`authenticateUser` `User.totpConfirmedAt`'i **zaten okuyor** — yeni sorgu gerekmiyor.

**İkinci yarı — kurulum sonrası tazeleme:** `confirmTotpSetup` başarılı olduğunda jeton
hâlâ `tfa: false` der (7 gün ömür). `jwt` geri çağrısında `trigger === 'update'` dalı
gerekiyor ki istemci `useSession().update()` çağırınca alan tazelensin. Bu dal olmadan
kullanıcı kurulumu bitirir ama panele giremez — **çıkıp yeniden girerek kurtulur, kilitlenme
yok, ama akış kötü.**

**Kabul kriterleri:**
- [ ] Jetonun yeni şekli: `{ sub, email, name, tfa, iat, exp }`
- [ ] `tfa` = `User.totpConfirmedAt != null`; yeni DB sorgusu **eklenmedi**
- [ ] Jetonda hâlâ hassas veri yok — `tfa` boolean, secret/kod/sayı **yok** (§8.20)
- [ ] `trigger === 'update'` dalı: `useSession().update()` sonrası `tfa` tazeleniyor
- [ ] Kurulum → tazeleme → panele erişim akışı **uçtan uca** doğrulanmış
- [ ] Güvenlik'in `requiresTwoFactorSetup`'ı **tüketiliyor**, yeniden yazılmıyor
- [ ] `src/lib/security/two-factor.ts`'e **dokunulmamış** (md5 değişmemeli)
- [ ] Birim testleri: `tfa: true` · `tfa: false` · `update` tetikleyicisi
- [ ] `pnpm lint && typecheck && test && build` temiz; `.env` olmadan da build EXIT 0

**Dışarıya sözleşme:** jetonun nihai şekli · `update()` çağrısının Frontend tarafındaki
kullanımı (T-036'nın devamında gerekecek) · geçiş penceresinin ne zaman kapandığı.
